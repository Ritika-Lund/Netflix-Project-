This is a beginner-friendly **Netflix Data Analysis** project where I analyzed a dataset of **9,000+ movies** to uncover trends and patterns that can support data-driven business decisions.

Netflix is well known for using **Data Science, AI, and Machine Learning** to understand customer behavior and build strong recommendation systems. This project focuses on exploring movie data to answer important business questions related to genres, popularity, ratings, and release trends.

## 📂 Dataset
- **File Name:** `mymoviedb.csv`
- **Size:** 9,000+ movie records
- **Includes:** movie title, genre, popularity, vote average, release year, and other attributes

  ## 🛠️ Tech Stack
- Python  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn

  ## ✅ Project Workflow
### 1) Data Collection & Cleaning
- Loaded the dataset into Pandas
- Checked missing values and duplicates
- Cleaned and prepared the dataset for analysis

### 2) Exploratory Data Analysis (EDA)
- Explored trends and patterns in the dataset
- Answered business questions using data insights

### 3) Data Visualization
- Created charts and graphs to present findings clearly
- Used Matplotlib and Seaborn for visualization

  ## ❓ Questions Answered
- What is the most frequent genre of movies released on Netflix?
- Which movie has the highest votes in the `vote_avg` column?
- What movie has the highest popularity and what is its genre?
- What movie has the lowest popularity and what is its genre?
- Which year has the most filmed movies?
